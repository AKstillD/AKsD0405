# AKstillDreamin' (에이케이 스틸 드리민)

## 프로젝트 개요
버추얼 휴먼 아이돌 밴드 **AKstillDreamin' (에이케이 스틸 드리민)**의 공식 프로젝트 기획서 웹사이트입니다.

**컨셉**: NEO HEROES FROM HISTORY. IDOLS FROM THE FUTURE.  
**슬로건**: 역사 속 영웅이 미래 아이돌로 귀환하다

---

## 🎭 프로젝트 특징

### 네오 히어로 (Neo Hero) 컨셉
한국 역사 속 위인들의 이름과 정신을 계승한 7인의 버추얼 아이돌이 밴드 연주와 퍼포먼스(댄스)를 동시에 소화하는 하이브리드 엔터테인먼트 프로젝트

### 3-Way 하이브리드 포맷
- **버추얼 휴먼** 기술 기반
- **라이브 밴드** 연주 (기타, 베이스, 드럼, 키보드, 바이올린)
- **K팝 퍼포먼스** (댄스 및 보컬)

## 👥 팀 구성

### 7명의 남성 멤버
1. **AK (Adrian K)** - 메인 보컬 / 기타 / 키보드 / 작곡 / 프로듀싱
   - 모티브: 프로젝트 원년 멤버, 팀의 정신적 지주
   - 비주얼: 안경을 쓴 지적이고 세련된 리더, 프로듀서 느낌의 차분한 카리스마

2. **세종 (SEJONG)** - 키보드 / 보컬
   - 모티브: 세종대왕 — 창조와 문명의 아이콘
   - 비주얼: 우아하고 고급스러운 클래식 아이돌, 왕의 품격

3. **순신 (SUNSIN)** - 보컬 / 베이스
   - 모티브: 이순신 장군 — 불굴의 의지와 전략
   - 비주얼: 밀리터리 재킷, 강렬한 포즈, 압도적인 존재감

4. **게토 (GETTO)** - 래퍼 / 보컬
   - 모티브: 자유와 저항의 정신
   - 비주얼: 거칠고 자유분방한 스트릿 패션, 사이버펑크 요소

5. **치우 (CHIWOO)** - 보컬 / 메인 기타
   - 모티브: 치우천왕 — 전쟁의 신, 원초적 에너지
   - 비주얼: 와일드한 에너지, 사이버펑크 스트릿 패션

6. **단군 (DANGOON)** - 드럼 / 보컬
   - 모티브: 단군왕검 — 한민족의 시조, 대지와 하늘의 연결
   - 비주얼: 원시적 에너지와 현대 스타일의 융합, 부족적 패턴
   - **스타일**: 이민호 느낌 - 샤프한 턱선, 강렬한 눈빛, 카리스마

7. **보고 (BOGO)** - 바이올린 / 하모니카 / 색소폰 / 보컬
   - 모티브: 장보고 — 해상왕, 개척과 교류의 정신
   - 비주얼: 우아하고 고급스러운 클래식 아이돌, 국제적 세련미
   - **스타일**: 차은우 느낌 - 완벽한 대칭 얼굴, 우아한 매력

### 여성 게스트 AI
8. **LA (Lumina Angel)** - 게스트 AI 보컬 / 댄스
   - 의미: "빛의 천사" - 미래를 밝히는 AI 존재
   - 모티브: 미래에서 온 AI 존재
   - 비주얼: 쿨뷰티 K-pop 아이돌 스타일, 실버-화이트 헤어, 현대적 하이패션
   - **스타일**: 윈터(aespa) 느낌 - 쿨한 매력, 샤프한 이목구비
   - **역할**: 보컬과 댄스 퍼포먼스를 담당하는 올라운더

## 🚀 기술 스택

### Frontend
- **HTML5**: 시맨틱 마크업
- **CSS3**: Glassmorphism, Animations, Flexbox, Grid
- **JavaScript (Vanilla)**: Particle Effects, Scroll Animations, Event Handlers
- **Google Fonts**: Orbitron (영문), Noto Sans KR (한글)
- **Font Awesome**: 소셜 미디어 아이콘

### 핵심 기능
1. **파티클 시스템**: Canvas API를 활용한 실시간 파티클 애니메이션
2. **스크롤 애니메이션**: Intersection Observer API 기반 요소 등장 효과
3. **스무스 스크롤**: 네비게이션 링크 클릭 시 부드러운 스크롤
4. **반응형 디자인**: 모바일 퍼스트 접근법
5. **성능 최적화**: Throttle/Debounce 적용

## 📞 배포 및 접근

### 로컬 실행 방법
1. 프로젝트 파일 다운로드
2. `index.html` 파일을 브라우저로 열기
3. 또는 로컬 서버 실행:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (http-server 설치 후)
   npx http-server
   ```
4. 브라우저에서 `http://localhost:8000` 접속

### 배포 방법
- **Publish 탭** 사용: 프로젝트를 원클릭으로 배포
- Netlify, Vercel, GitHub Pages 등 정적 호스팅 서비스 이용 가능
